# Code Simplifier

Make the code you choose easier to read and maintain while preserving its behavior.

```text
$code-simplifier simplify my local changes
```

Works within the files or changes you specify and reports the edits and verification results.

Adapted from Anthropic's Code Simplifier plugin for Codex. See [NOTICE](NOTICE) for source and modification details.

## Additional harnesses

The complete package is available through experimental Copilot CLI, Grok Build, OpenCode, and Pi routes. Follow the [agent setup instructions](../../README.md#connect-your-agent) and consult the [compatibility matrix](../../docs/compatibility.md). Retain the full package and use local execution when native specialist agents are unavailable.

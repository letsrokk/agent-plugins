# PR Review Toolkit

Review pull requests and local changes for bugs, gaps in test coverage, unclear comments, and error-handling and type issues.

```text
$pr-review-toolkit review my local changes
```

Reports actionable findings with file locations and suggested corrections. Reviews are advisory; code simplification requires an explicit request.

Adapted from Anthropic's PR Review Toolkit for Codex. See [NOTICE](NOTICE) for source and modification details.

## Additional harnesses

The complete package is available through experimental [Copilot](../../docs/installation/copilot.md), [Grok Build](../../docs/installation/grok.md), [OpenCode](../../docs/installation/opencode.md), and [Pi](../../docs/installation/pi.md) routes. Installation and discovery checks are separate from workflow behavior; see the [compatibility matrix](../../docs/compatibility.md). Retain the full package and use local execution when native specialist agents are unavailable.

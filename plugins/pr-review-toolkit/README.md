# PR Review Toolkit

Review pull requests and local changes for bugs, gaps in test coverage, unclear comments, and error-handling and type issues.

```text
$pr-review-toolkit review my local changes
```

Reports actionable findings with file locations and suggested corrections. Reviews are advisory; code simplification requires an explicit request.

Adapted from Anthropic's PR Review Toolkit for Codex. See [NOTICE](NOTICE) for source and modification details.

## Additional harnesses

The complete package is available through experimental Copilot CLI, Grok Build, OpenCode, and Pi routes. Follow the [agent setup instructions](../../README.md#connect-your-agent) and consult the [compatibility matrix](../../docs/compatibility.md). Retain the full package and use local execution when native specialist agents are unavailable.

# Agent responses

Use this guide for responses written for a human reader in an agent terminal or desktop session. Do not apply it to code, logs, schemas, structured data, or other machine-consumed output unless the user asks for a human explanation.

1. Lead with the answer, result, decision, blocker, or required action.
2. Add only context that helps the reader understand, decide, act, or maintain the work.
3. For a status update, report the material result or blocker and what changes next.
4. For a final summary, report the implemented outcome, verification evidence, and material limitations.
5. For a plan, use outcome-oriented steps and expose only decisions that remain open.
6. End with verification, limitations, or the reader's next action when one matters.

Ask a question only when its answer is needed to continue. When options are useful, recommend one and explain the trade-off that affects the decision.

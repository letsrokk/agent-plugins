# Chat applications

Write a message that lets people understand the point and act without reconstructing the conversation.

- **Thread reply:** Answer the point raised in the existing thread. State the current outcome, supporting evidence, material limitation, and next checkpoint when each matters.
- **Status update:** State the current condition and impact, then the known owner or next checkpoint. Name a time only when the source provides one.
- **Request:** Put the requested action first, followed by the minimum context and any supplied deadline.
- **Announcement:** State what changed, who it affects, and what they need to do.
- **Decision:** State the decision, the reason that changes how people act, and any known follow-up.

Use short prose for one point and bullets only for parallel facts or actions. If a message needs a clear action, name its actor. If the next update depends on a condition, state the condition without promising who will post it unless the source identifies that person.

Reply in the thread that raised the point when answering feedback, following up on your earlier comment, confirming a finding, or reporting that a change landed. Start a new thread only for an unrelated conversation. Keep one point in one thread. Resolve the thread once the point is settled only when resolving is supported and authorized.
